# 참고 문헌

이 프로젝트가 따르는 공식 가이드(예: Open API 활용가이드), 근거 문헌, 데이터 설명서를 둔다. 파일로 받은 것은 이 폴더에 넣고, 주소만 있는 것은 아래에 한 줄씩 적는다.

- 국립중앙도서관 국가서지 LOD SPARQL 질의 주소: https://lod.nl.go.kr/sparql
- 도서관 정보나루 Open API 활용방법: https://www.data4library.kr/apiUtilization
- 알라딘 Open API 매뉴얼: 알라딘 TTB 서비스에서 받는 문서이고, 받은 파일을 이 폴더에 넣는다
- 부산광역시립시민도서관 원북원부산 소개: https://home.pen.go.kr/siminlib/cm/cntnts/cntntsView.do?mi=13256&cntntsId=1462
- 국립중앙도서관 홈페이지: https://www.nl.go.kr

아래 파일은 이 저장소에 넣지 않았다. 위 주소나 제공 기관에서 받아 이 폴더에 넣는다.

- 도서관 정보나루 Open API 매뉴얼: `도서관정보나루_API_Manual.pdf`
- 도서관 정보나루 MCP 매뉴얼: `도서관정보나루_MCP_Manual.pdf`
- 국립중앙도서관 소장자료 Open API 가이드(v2.6): `소장자료_OPENAPI_GUIDE_v2.6.doc`
