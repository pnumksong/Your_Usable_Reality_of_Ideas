# 구상 문서

## 목표

작업 공간의 다른 프로젝트와 우리 학과 학생을 위해, 도서관 관련 공개 데이터를 받아, 출처와 받은 날이 붙은 파일로 `Data/`에 쌓는 수집 프로젝트

## 실현 모습

요청하면 정한 출처에서 정한 항목을 받아 CSV나 JSON으로 `Data/`에 저장하고, `Data/README.md`에 출처와 받은 날과 건수가 한 줄씩 남는다. 제목 검색과 책 추천 프로젝트는 이 파일을 읽어 쓴다.

## 예상 질문

- 이용자 질문 1: 받은 자료의 출처와 받은 시점
- 이용자 질문 2: 받은 값이 원본과 같은지 확인하는 방법
- 내부 질문: 사이트의 이용 약관과 호출 제한

## 구체적 요구사항

- 문제: 필요한 도서 데이터가 서비스마다 흩어져 있고 형식이 다르다
- 사용자: 작업 공간의 다른 프로젝트, 문헌정보학과 학생
- 쓸 자료: 국립중앙도서관 홈페이지 메뉴, 국가서지 LOD(SPARQL), 도서관 정보나루 Open API 대출 순위, 알라딘 Open API 베스트셀러, 원북원부산 선정 목록
- 제외 범위: 개인정보, 로그인이 필요한 페이지, 이용 약관이 금지한 수집

## 기능 구성

가장 작은 첫 버전부터 차례로 쓴다.

| 순서 | 기능 | 기능의 목표 | 근거자료(데이터, 참고자료) |
|---|---|---|---|
| 1 | 메뉴 링크 수집 | 국립중앙도서관 첫 화면의 주요 메뉴 이름과 링크를 CSV로 저장함 | 국립중앙도서관 홈페이지와 robots.txt |
| 2 | 책 목록과 대출 순위 수집 | 국가서지 LOD의 책 목록과 정보나루 대출 순위를 받아 저장함 | `reference/`의 LOD SPARQL 주소와 정보나루 Open API 활용방법 |
| 3 | 추천용 목록과 소개 수집 | 베스트셀러, 원북원부산 선정 목록, 책 소개를 받아 책 추천 프로젝트가 쓰게 저장함 | `reference/`의 알라딘 Open API 매뉴얼과 원북원부산 소개 |

- 기능 간 흐름: 받기(1, 2, 3) → `Data/`에 저장 → `Data/README.md`에 출처, 받은 날, 건수 기록 → 다른 프로젝트가 읽음
