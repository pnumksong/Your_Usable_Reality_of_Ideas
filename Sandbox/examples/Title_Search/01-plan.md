# 구상 문서

## 목표

우리 도서관 이용자를 위해, 국가서지 책 목록을 넣어, 검색어가 든 책을 찾아 주는 화면

## 실현 모습

이용자가 화면을 열면 책 목록이 보이고, 검색 칸에 낱말을 넣으면 제목에 그 낱말이 든 책만 남으며, 찾은 책의 수가 함께 보인다.

## 예상 질문

- 이용자 질문 1: 저자와 출판사 검색 지원 범위
- 이용자 질문 2: 우리 도서관 소장 확인
- 내부 질문: 책 목록 갱신 주기

## 구체적 요구사항

- 문제: 목록 파일을 열어 눈으로 찾기 어렵다
- 사용자: 우리 도서관 이용자
- 쓸 자료: `Data/`의 국가서지 책 목록 CSV(도구에게 국가서지 LOD에서 조건에 맞는 도서를 질의해 JSON으로 저장하고 제목, 저자, 발행 연도만 CSV로 정리하게 해서 모음)
- 제외 범위: 소장 확인, 로그인

## 기능 구성

가장 작은 첫 버전부터 차례로 쓴다.

| 순서 | 기능 | 기능의 목표 | 근거 문헌과 데이터 |
|---|---|---|---|
| 1 | 책 목록 보기 | 받은 책 목록을 화면에 표로 보임 | `Data/`의 국가서지 책 목록 CSV |
| 2 | 제목 검색 | 검색 칸의 낱말이 제목에 든 책만 남김 | 같은 CSV의 제목 칸 |
| 3 | 찾은 책 수 표시 | 남은 책의 수를 함께 보임 | 제목 검색의 결과 |

- 기능 간 흐름: 목록 읽기(1) → 낱말로 거르기(2) → 남은 수 표시(3)
