# 구상 문서

## 목표

부산대학교 학생을 위해, 학칙과 학사 규정의 조문을 넣어, 휴학과 수업과 졸업과 장학 같은 학사 질문에 맞는 근거 조문을 찾아 보여 주는 학사행정 지원 챗봇

## 실현 모습

학생이 화면에 「휴학은 몇 학기까지 할 수 있나요」처럼 물으면 관련 조문이 규정명, 조, 발령일자와 함께 나오고, 원문 링크를 눌러 국가법령정보센터에서 원문을 확인한다.

## 예상 질문

- 이용자 질문 1: 조항의 현행 효력
- 이용자 질문 2: 규정에 없는 사항의 문의처
- 내부 질문: 규정 개정 시 조문 갱신 시점

## 구체적 요구사항

- 문제: 부산대학교 규정이 200건이 넘고 조문이 길어 필요한 조항을 찾기 어렵다
- 사용자: 부산대학교 학생
- 쓸 자료: 부산대학교 규정 목록과 조문(법령 MCP로 조회하거나 법제처 국가법령정보 Open API로 받아 `Data/`에 둠)
- 제외 범위: 규정의 해석과 판단, 상담 내용 저장, 담당자 개인정보

## 기능 구성

가장 작은 첫 버전부터 차례로 쓴다.

| 순서 | 기능 | 기능의 목표 | 근거 문헌과 데이터 |
|---|---|---|---|
| 1 | 질문으로 조문 찾기 | 학사 질문의 낱말로 관련 조문을 찾음 | 부산대학교 규정 목록과 조문, `reference/`의 법제처 Open API 활용가이드 |
| 2 | 근거 표시 | 조문마다 규정명, 조, 발령일자, 원문 링크를 보임 | 같은 조문 자료, 국가법령정보센터 원문 |
| 3 | 분야별 거르기 | 학적과 학위, 교육과정과 수업, 장학으로 좁힘 | 규정 이름의 분야 |

- 기능 간 흐름: 질문 입력 → 조문 찾기(1) → 분야로 거르기(3) → 근거와 함께 표시(2)
