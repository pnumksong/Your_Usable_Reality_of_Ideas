# 참고 문헌

이 프로젝트가 따르는 공식 가이드(예: Open API 활용가이드), 근거 문헌, 데이터 설명서를 둔다. 파일로 받은 것은 이 폴더에 넣고, 주소만 있는 것은 아래에 한 줄씩 적는다.

- 법제처 국가법령정보 공동활용 OPEN API 활용가이드: https://open.law.go.kr/LSO/openApi/guideList.do
- korean-law-mcp(법령 MCP): https://github.com/chrisryugj/korean-law-mcp

아래 파일은 이 저장소에 넣지 않았다. 위 주소나 제공 기관에서 다운로드해 이 폴더에 넣는다.

- 법제처 국가법령정보 공유서비스 Open API 활용가이드(2022-10-19): `국가법령정보공유서비스_GW_Open API 활용가이드_20221019.docx`
