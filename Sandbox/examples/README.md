# 예시 프로젝트

프로젝트를 만들어 쓰는 모습을 보여 주는 예시 넷이다. 그대로 두고 읽기만 해도 되고, 승격해서 내 프로젝트로 시작해도 된다.

| 예시 | 하는 일 |
|---|---|
| `Library_Data_Collection` | 국립중앙도서관 홈페이지 메뉴, 국가서지 LOD의 2026년 한국소설, 도서관 정보나루의 대출 순위를 모아 `Data/`에 쌓음 |
| `Title_Search` | 국가서지 책 목록에서 검색어가 든 책을 찾아 주는 화면 |
| `PNU_Regulation_Chatbot` | 부산대학교 학칙과 학사 규정으로 학사 질문에 답하는 학사행정 지원 챗봇 |
| `Book_Recommender` | `Data/`의 베스트셀러와 대출 상위와 원북원부산 목록으로 질문에 맞는 책을 추천하는 챗봇 |

- 승격 요청 예: 「Sandbox/examples의 Library_Data_Collection을 프로젝트로 승격해 줘」
- 예시 안의 경로(`Projects/…`)는 승격한 뒤의 자리를 가리킨다.
