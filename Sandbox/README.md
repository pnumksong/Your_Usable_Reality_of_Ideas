# 연습

이 폴더는 연습과 생각 정리를 하는 곳이다. 마음대로 고치고 지워도 된다.

- 생각 정리: 떠오른 것을 `ideas.md`에 적는다. 구상 문서를 쓰기 전의 가벼운 메모다.
- 연습: 해 보고 싶은 요청의 결과는 `practice/`에 둔다. 연습마다 폴더를 하나씩 만들면 하나만 골라 승격하기 쉽다.
- 예시 프로젝트 넷은 `examples/`에 있다.
- 이 폴더에서 한 일은 기록하지 않는다. 프로젝트의 작업은 이 폴더를 참조하지 않는다.

## 프로젝트로 승격

생각이 굳거나 연습 결과를 이어 가고 싶으면 언제든 프로젝트로 승격한다.

- 요청 예: 「Sandbox의 ○○ 메모와 practice의 ○○ 폴더를 프로젝트로 승격해 줘. 프로젝트 이름은 ○○」
- 도구가 목표를 먼저 묻고, 틀을 복사해 새 프로젝트를 만들고, 메모를 구상 문서로, 결과를 그 프로젝트의 `data/`나 `output/`으로 옮긴다. 참조하던 자료와 새 프로젝트가 서로를 가리키도록 적고, 여기 원래 자리에는 승격한 곳을 남긴다.
- 그때부터는 프로젝트의 지침과 기록 규칙을 따른다.
